- Express Validator

 : Validator is a kind of middle ware
 : Define the validator middle ware in routers and check the result in controller

  router.post(
    "/",
    [
      check("title").not().isEmpty(),
      check("description").isLength({ min: 5 }),
      check("address").not().isEmpty(),
