- html를 서버에서 templating 하는 이전 방식에서는 서버에서 session을 관리하고, client에는 cookie로 session id를 기억하는 방식으로 authentication 이 작동했다.
- SPA(Single Page Application) 방식에서는 stateless & decoupled from frontend
- SPA에서는 token을 생성하고, client는 이를 Cookie 또는 localStorage에 저장하여 사용함
- 서버에서는 token을 private key로 암호화하여 client에 전송하여 token 위변조를 방지함
- token 생성은 JWT (JSON Web Tokens) 방식을 사용함 (https://jwt.io/)
- 서버는 token을 저장하지 않으며 token의 private key를 이용하여 위변조 여부만 판단한다.
- frontend 에서는 localStorage에 userId, token, expirationDate 을 저장하여 로그인을 관리한다
- localStorage는 chrome debugging tool 로 열어볼 수 있다.
- javascript setTimeout을 이용하여 expirationDate 가 되면 자동 logout 되는 기능도 구현 가능하다.
- Authentication은 login/logout 과정을 의미하고, Authorization은 특정 resource에 대한 access를 허용할 것인가를 의미한다.
